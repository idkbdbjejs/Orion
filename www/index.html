SO LÄUFT ES NICHT

So bringst du es in zwei Minuten zum Laufen:

  1. Gehe auf app.netlify.com/drop
  2. Ziehe die Datei index.html in das Feld
  3. Du bekommst eine Adresse mit https://
  4. Diese Adresse öffnen — dort funktioniert alles

Grund: Browser geben Mikrofon, Kamera und Bildschirm nur über eine verschlüsselte Verbindung frei. Eine Datei aus dem Ordner gilt nicht als solche. Das ist keine Einstellung, die man umgehen kann.
